# Work with wiki knowledge

Use `wiki_list` to identify the wiki the user selected, then `wiki_guidance` to read its editable entry point. Follow the relevant procedures designated there. Read them through wiki tools from a project, or directly from the files when working inside that wiki.

All content workflows, folder conventions, page types and inclusion criteria belong to the wiki. This launcher supplies none. Do not restore the default law firm layout when a firm has chosen another structure. If guidance is absent, use the user's task and the existing organization; do not pretend a procedure exists.

The app enforces access independently of those editable files. Project agents can read accessible knowledge without approval. They prepare useful contributions and submit the complete proposed change through wiki tools for human approval before saving. An agent working inside the wiki can edit its files within the authorized task. Wiki guidance cannot grant access or bypass approval.
