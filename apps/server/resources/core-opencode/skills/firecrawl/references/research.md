# Research briefs

Use the requested topic, jurisdiction, date and deliverable from the conversation. Scale collection to the question. A quick answer needs only enough evidence to support it; a formal report can require several research angles. Clarify a material scope or time-budget gap before a lengthy investigation, without imposing an interview on a routine lookup.

Search by the actual question and useful alternative terms, then read the best primary sources. For legal research, follow [Government research](government.md). For a report whose evidence base is scientific papers, use the available paper-index tools to inspect relevant passages; ordinary web search alone is not a literature review.

As evidence is collected, keep claim-to-source associations: source title and URL, supporting quotation/passage, evidenced pinpoint/date, and limitations. Reuse retrieved pages. Resolve material disagreements through the underlying sources; distinguish source statements, your synthesis and open questions.

## Deliverable prompts

Adapt these structures to the user's requested format and existing firm templates.

For a short research brief:

> State the answer first. Explain the material findings with source links beside the claims. Quote or identify the supporting sections where useful. Close with unresolved questions or limitations that change the conclusion. Include a compact source list with a one-line explanation of each source's relevance when that helps review.

For an explicitly requested formal report:

> Prepare an executive summary, supported findings and analysis, contrary evidence or risks, open questions, and a source register. Preserve the research question, jurisdiction/date and material collection limits so another reviewer can understand the scope. Link factual claims to the original publications and distinguish quotation from interpretation.

Save an artifact only when the request calls for it, using the normal LegalWork document/notes workflow and the requested format. A source register should reference material actually relied on, not every search result. Do not imply that the brief was checked against sources that were unavailable or only appeared as titles/snippets.
